**見どころ**

## 4 つのモード

表現したいものによって、流体の適した解き方は違います。混ざり合う煙やインクなら格子法、水面が割れて飛沫が飛ぶ表現なら粒子と格子を往復させる方法。その違いを自分で確かめたくて、同じ UI に 4 つ並べました。

### インク（2D Stable Fluids・GPU）

ドラッグの軌跡に沿って発光インクを流し込む格子法の流体。渦度強化で、数値粘性に潰される小さな渦を復元している

![インクモード: 発光インクが渦を巻いて混ざり合う様子](docs/portfolio/ink-poster.webp)

*ドラッグ 2 回ぶんのインクが、渦を生みながら混ざっていく*

### 水 2D（FLIP/PIC）

粒子と MAC グリッドを往復させる水槽。水面はメタボールで抜くので、砕けた飛沫がそのまま粒として分離する

![水2Dモード: 崩れた水が壁を駆け上がり飛沫を飛ばす様子](docs/portfolio/water2d-poster.webp)

*ダムブレイク。壁を駆け上がった水が砕けて粒に分かれる*

### 水 3D（3D FLIP + SSFR）

立体の水槽。水面のメッシュを作らず、スクリーンスペース流体レンダリングで描く。球体でかき混ぜられる

![水3Dモード: 立方体の水槽の中で球体が水をかき混ぜる様子](docs/portfolio/water3d-poster.webp)

*球体が水をかき混ぜ、後ろに泡の尾を引く*

### 地球（球面浅水方程式）

全球の海を回す惑星モード。地形は毎回手続き生成され、雨は川になって流れ下る。月と太陽の潮汐、コリオリ力、自転軸の傾きによる季節つき

![地球モード: 手続き生成された大陸と海を持つ惑星](docs/portfolio/earth-poster.webp)

*雨を降らせた惑星。昼夜境界・大気の縁光・月がシミュレーション時刻に同期する*

## つまずいたところ

FLIP/PIC は速度を粒子に持たせ、非圧縮条件だけを格子上で解くハイブリッドです。難しかったのは数式ではなく処理の順序でした。速度差分に使う前フレームの格子速度を、粒子→格子転送の後・圧力射影の前で保存しないと、差分に自分自身の更新が混ざって数十フレームで発散します。

地球モードは緯度経度 2048×1024 の格子で解いています。重力波の CFL 条件は水深と重力で決まるので、UI の重力スライダーを動かすと簡単に破綻します。毎フレーム CFL からサブステップ数を計算し、どこまで振っても壊れないようにしました。

### 静止時のドリフト

微小な速度が積み上がって水面が揺れ続けるので、ドリフト補正のデッドバンドを入れて止めた

### 壁への貼り付き

境界で速度を全成分固定すると壁に貼り付くため、壁に向かう流束だけを止める方向性クランプに変えた

## 地形と水面の描画

### 大陸と川

低周波 fbm を分位点で正規化し、シードによらず陸地率が約 48% になるようにした。川は山の湧点から最急降下を追って谷を彫る。ノイズ合成（約 200 万セル）は GPU、逐次処理の川だけ CPU

### 海面

球面のハイトフィールドをレイマーチ＋二分法で交差判定する。法線は B スプライン双三次サンプリングで取り、バイリニア由来のセル状のファセットを消した

## 配布と検証

配るのは 219KB の HTML ファイル 1 つです。4,300 行を 1 ファイルで書くのは読めたものではないので、ソースは役割ごとに分割し、依存ゼロのビルドスクリプトで連結しています。

文字列に埋め込んだ GLSL は `node --check` を素通りします。実際、予約語 `patch` を変数名に使って全モードが起動しなくなったことがあるので、ヘッドレス Chromium で全モードを生成して数フレーム進めるスモークテストを用意しました。

## 生成 AI の活用について

- 実装したい手法（Stable Fluids・FLIP/PIC・球面浅水方程式・SSFR）と、モード構成・UI の設計は自分が決めた
- 発散・貼り付き・ドリフトといった不具合は現象から原因を切り分けたうえで指示し、AI には実装とパラメータ調整の試行を担当させた
- シェーダを触るたびにヘッドレス Chromium のスモークテストを通す運用を決め、目視でしか判定できない見た目の受け入れは自分で行った
