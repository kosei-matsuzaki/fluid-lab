# Fluid Lab

ブラウザで動くインタラクティブ流体シミュレーション。単一HTMLファイル(依存なし・ビルド不要)で、4つのモードを切り替えられる。

**公開版**: https://claude.ai/code/artifact/d3e7d264-c467-42cd-9a98-2e2d9c2df422

## 実行方法

`fluid-lab.html` をブラウザで開くだけ。WebGL2 + `EXT_color_buffer_float` があるとフル品質(GPU海洋シミュレーション・高解像度地形)、ない環境ではCPUフォールバックで動作する。

## モード

| モード | キー | 内容 |
|---|---|---|
| インク | 1 | 2D Stable Fluids(GPU)。渦度強化つきのインク流体 |
| 水 2D | 2 | FLIP/PIC ハイブリッド水槽。メタボール水面レンダリング |
| 水 3D | 3 | 3D FLIP水槽。スクリーンスペース流体レンダリング(SSFR) |
| 地球 | 4 | 全球シミュレーション。球面浅水方程式の海+レイマーチ地形 |

共通: Space=一時停止、S=サイドバー開閉。各アクションのショートカットはボタンのかっこ書きに表示。

## 技術メモ

### 水 2D / 3D — FLIP/PIC
- MACグリッド、P2G/G2P転送、Gauss–Seidel圧力解法(過緩和1.9)
- FLIPの要点: prevU/V/Wのスナップショットは「粒子→格子転送の後・圧力射影の前」に取る(でないと毎フレーム自己増幅する)
- 静止安定化: ドリフト補正にデッドバンド、境界は「壁内向き流束のみブロック」する方向性クランプ(全ピン留めはNoSlipの貼り付きを生む)
- 3D描画: 球面インポスタ深度 → 深度依存分離ブラー → 厚みパス → 屈折/フレネル/Beer–Lambert合成

### 地球 — 球面浅水方程式(SWE)
- 緯度経度2048×1024格子(地形テーブルと1セル1対1)、状態(h, u, v)をWebGL2フラグメントシェーダでピンポン求積
- 運動量: 自由表面勾配 + 潮汐加速度(月+太陽0.45倍)+ コリオリ力、連続式: 風上流束+球面計量、極はミラー処理
- 重力波CFLに合わせて自動サブステップ(重力スライダー連動)
- 雨はストームセルから水深を直接加算し、浅水流として斜面を流下して川になる
- 天体: 太陽日:恒星日 = 1+1/365.25、朔望月27.32日、自転軸傾斜による季節、カメラはシミュレーション時刻に同期

### 地形生成
- 大陸: 低周波fbm + 分位点正規化で陸地率~48%を保証
- 山脈: ridgedノイズ、川: 山の湧点から最急降下で追跡して谷を彫る(逐次処理なのでCPU)
- ノイズ合成パスはGPU(2Mセル)→readPixelsで読み戻して川を彫る

### レンダリング(地球)
- 球面ハイトフィールドのレイマーチ+二分法。海面=地形と水面の高い方
- 法線はBスプライン双三次サンプリング(バイリニアのセル状ファセット除去)
- 海面: 尖った波頭の方向性波6本 + 風のむら + 白波 + 流速由来の泡 + 海岸の泡線。格子以下のスケールはカメラ接近でフェードインするプロシージャルディテール
- 昼夜境界、大気の縁光、月(位相・深度書き込みつき実球)

### 開発時の検証
`node --check` はGLSLを検出できない。シェーダ変更時はヘッドレスChromium(Playwrightキャッシュの `chrome --headless=new --enable-unsafe-swiftshader`)で全モード生成+数フレーム実行のスモークテストを通すこと(GLSL予約語 `patch` で全滅した事故あり)。
